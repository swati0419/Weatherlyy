# Weatherlyy 🌤️ 
A modern weather forecasting web application built with React, Tailwind CSS, and OpenWeather API.
Weatherlyy provides real-time weather updates, dynamic weather-based UI, and a clean glassmorphism-inspired interface with smooth user experience.

---

## ✨ Features

- 🌎 Real-time weather data
- 🔍 Search weather by city
- 📅 5-day weather forecast
- 🎨 Dynamic weather-based backgrounds
- 🧊 Glassmorphism UI design
- ⚡ Fast and responsive interface
- 📱 Fully responsive for mobile and desktop
- 🌡️ Temperature, humidity, pressure & wind details
- ☁️ Dynamic weather icons
- 🌈 Modern gradient UI with animations

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- Vite
- OpenWeather API
- Lucide React Icons
